## The Fusion Capstone — GPU LLM Inference Engine

Your 2027 capstone builds on 2026's CPU engine and goes production-curious:

- Port the forward pass to CUDA / Triton kernels.
- Implement a **paged KV cache** (read vLLM's paper + source).
- Implement **continuous batching** with a proper scheduler.
- Add **INT4 / INT8 quantization** for weights.
- Benchmark vs vLLM on one model (e.g., Llama-3-8B): tokens/sec, time-to-first-token, p99 latency.
- Submit at least one PR upstream to vLLM, Triton, or SGLang based on what you learned.

This is what gets you hired at Together, Fireworks, Anyscale, Modal, Baseten, or the vLLM core team.

## What NOT to Do in 2027

- Don't skip Nsight profiling. CUDA without profiling is guesswork.
- Don't write CUDA C before you've written CUDA kernels in PTX at least once — you need the abstraction level floor.
- Don't implement quantization by copy-pasting. Derive the math.
- Don't touch MLIR or Triton DSL yet (Q1–Q3). Ordinary CUDA first. Triton last quarter only.
- Don't start a distributed systems project before MIT 6.5840 Raft lab is working and under test.
