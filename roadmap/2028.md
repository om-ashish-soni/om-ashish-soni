# 2028 — Compilers & Serving

**Theme.** Go up the stack — from writing kernels by hand to teaching compilers how to write them. Own the inference pipeline end-to-end.

**AI integration.** Master the serving layer: speculative decoding, Medusa, continuous batching, structured generation, agent frameworks. Understand RLHF / DPO / GRPO at the mechanics level, not just vibe level.

**End-of-year ceiling.**
- Write real LLVM passes and MLIR dialects.
- Contribute to Triton / MLIR / torch.compile internals.
- Production-grade inference stack you own end-to-end.
- One novel optimization contributed to a major OSS inference project.
- Agent framework internals understood deeply (pairs with mo-code).

## Systems Track — Resources

### Books
1. **Engineering a Compiler** — Cooper & Torczon — the compiler textbook that respects your time.
2. **Dragon Book** — Aho, Lam, Sethi, Ullman — reference only; skim the relevant chapters.
3. **LLVM Essentials** / **Getting Started with LLVM Core Libraries** — Pandey et al. — practical LLVM.
4. **Crafting Interpreters** — Bob Nystrom — free online, world-class pedagogy; warm-up if rusty.
5. **Database Systems: The Complete Book** — Garcia-Molina et al. — for query-compiler parallels.

### Courses & Resources
- **Stanford CS143** — Compilers (classic, heavy on parsing + codegen).
- **LLVM Tutorial** — `llvm.org/docs/tutorial/` — Kaleidoscope chapters.
- **MLIR Tutorial** — `mlir.llvm.org/docs/Tutorials/` — Toy dialect walkthrough.
- **MLSys conference recordings** — watch the compiler and runtime tracks yearly.

### Papers
- Lattner & Adve — *LLVM: A Compilation Framework for Lifelong Program Analysis and Transformation*.
- Lattner et al. — *MLIR: A Compiler Infrastructure for the End of Moore's Law*.
- Tillet et al. — *Triton: An Intermediate Language and Compiler for Tiled Neural Network Computations*.
- Ragan-Kelley et al. — *Halide*.
- Chen et al. — *TVM*.
- Jouppi et al. — TPU v1 / v2 / v3 / v4 architecture papers (revisit — you'll read them differently now).
- Leviathan et al. — *Fast Inference from Transformers via Speculative Decoding*.
- Cai et al. — *Medusa: Simple LLM Inference Acceleration*.
- Li et al. — *EAGLE-2* / *EAGLE-3*.

### Code to Read
- LLVM `lib/Transforms/Scalar/` — start with small passes (DeadCodeElimination, SCCP).
- MLIR upstream `mlir/lib/Dialect/` — Linalg, Tensor, Affine dialects.
- OpenAI Triton compiler pipeline (Python → TritonIR → TritonGPUIR → PTX).
- vLLM scheduler + engine core.
- TensorRT-LLM example plugins.
- SGLang runtime.
- `torch/_inductor/` — PyTorch's inductor compiler.

### Projects
- [ ] Write an LLVM pass that performs a non-trivial transform (loop unrolling with a heuristic, or a dataflow analysis).
- [ ] Build an MLIR dialect for a toy DSL — lowering to LLVM or Linalg.
- [ ] Port a CUDA kernel you wrote in 2027 to Triton; benchmark.
- [ ] Write an autotuner for a parameterized kernel (search over tile sizes, warp counts).
- [ ] Land a non-trivial PR to Triton, MLIR, torch.compile, or TVM.

## The Fusion Capstone — Production Inference Stack With a Novel Optimization

By year end you should have a **production-grade inference stack** (built up over 2026→2028) that:

- Serves a real open-weights model at competitive throughput and latency.
- Uses a paged KV cache, continuous batching, INT4 / FP8 quantization.
- Implements speculative decoding.
- Has at least **one novel optimization** you can blog/paper about — a fused kernel, a scheduler heuristic, a compiler pass, a cache policy. The novelty is what makes it a moat artifact.

And at least **one merged upstream PR** to a major project (Triton / MLIR / vLLM / SGLang / torch.compile / TensorRT-LLM).

## What NOT to Do in 2028

- Don't skip Crafting Interpreters if you've never written an interpreter. The foundation is cheap and the payoff is large.
- Don't try to write an MLIR dialect before finishing the Toy tutorial twice.
- Don't read papers you can't implement. If a paper is beyond your CUDA chops, it's a 2027 gap — close it.
- Don't start on hardware. Year 2029.
- Don't get sucked into framework wars (PyTorch vs JAX vs MLX). Pick one, ship.
