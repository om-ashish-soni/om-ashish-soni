# 2029 — Silicon & Scale

**Theme.** Descend below the firmware line. Design custom silicon, FPGA accelerators, and understand production AI clusters at 10k-GPU scale.

**AI integration.** Study AI chip architecture — TPU, Trainium, Groq LPU, Cerebras, Tenstorrent, SambaNova — not as brand names but as dataflow and memory architectures. Learn what it takes to co-design a model and a chip.

**End-of-year ceiling.**
- Design and simulate a multi-stage RISC-V pipeline in Chisel.
- Build and run an FPGA systolic array for GEMM.
- Understand TPU/Trainium internals well enough to reason about bottlenecks.
- Grasp datacenter-scale distributed training (10k+ GPU runs).
- First conference-submitted paper (workshop tier acceptable).

1. **Digital Design and Computer Architecture, RISC-V Edition** — Harris & Harris — the right-sized intro.
2. **Computer Architecture: A Quantitative Approach** — H&P — reread with silicon eyes.
3. **Patterson & Hennessy — Computer Organization and Design, RISC-V Ed.** — revisit as a hardware book this time.
4. **Chisel Book** — Martin Schoeberl, *Digital Design with Chisel* — free online.
5. **The Datacenter as a Computer** — Barroso, Hölzle, Ranganathan — the foundational datacenter text.
6. **Site Reliability Engineering** — Beyer et al. (Google) — production operations canon.

## AI Track — Resources

### Chip architecture studies
Read each chip's papers + blog posts + available RTL/ISA docs, then write a one-page "if I were the architect" critique:

- **Google TPU** v1→v5 — systolic array evolution, BF16 choices, inter-chip links.
- **AWS Trainium / Inferentia** — NeuronCore architecture.
- **Groq LPU** — deterministic scheduling, single-core throughput model.
- **Cerebras WSE** — wafer-scale integration, weight streaming.
- **Tenstorrent** — Tensix cores, packet-based dataflow.
- **SambaNova** — reconfigurable dataflow units.
- **NVIDIA Hopper / Blackwell** — Tensor Memory Accelerator, transformer engine.

## The Fusion Capstone — FPGA Accelerator for Attention

Your 2029 capstone:

- Implement a systolic array in Chisel, synthesized on a real FPGA.
- Run a meaningful operation: GEMM first, then attention (Q·K^T then softmax then ·V) with a small token budget.
- Compare against CPU and a discrete GPU on latency, energy per token, area.
- Write it up as a detailed blog post — and ideally a workshop paper.

This is what moves you from *"I can write AI infrastructure software"* to *"I understand the silicon underneath well enough to co-design."* That's the apex moat.

## What NOT to Do in 2029

- Don't try to tape out silicon. You don't have a fab. FPGA is the right target for a solo learner.
- Don't start a chip startup in 2029 just because it's trendy. Finish the roadmap.
- Don't conflate verification with simulation. Verilator runs; verification requires testbenches.
- Don't buy the most expensive FPGA board. Start cheap (ULX3S or TinyFPGA) and learn the toolchain.
- Don't neglect the AI track this year just because the systems track is exotic. You'll regret losing inference-stack fluency.
